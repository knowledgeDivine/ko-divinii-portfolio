NOT AN ORDINAR MIND — XAMPP INSTALLATION

1. Copy this folder into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Create/import the database by importing database.sql.
5. Open http://localhost/not_an_ordinar_mind/

Default MySQL settings in config/db.php:
Host: localhost
Database: not_an_ordinar_mind
User: root
Password: (empty)

The site uses a CSS-built 3D sneaker and interactive pointer movement, so no 3D software or build process is required.
