MIMI HOMES — XAMPP INSTALLATION

1. Extract the "mimi_homes" folder into:
   C:\xampp\htdocs\

2. Start Apache and MySQL from the XAMPP Control Panel.

3. Open phpMyAdmin:
   http://localhost/phpmyadmin/

4. Create/import the database:
   - Click Import
   - Select database.sql
   - Execute it
   Database name: mimi_homes_db

5. Open the website:
   http://localhost/mimi_homes/

DATABASE CONFIG:
Host: localhost
User: root
Password: (blank by default in XAMPP)
Database: mimi_homes_db

The property images use remote Unsplash image URLs, so an internet connection is needed for the sample photos. Replace the image URLs in the properties table with your own local images whenever you are ready.
