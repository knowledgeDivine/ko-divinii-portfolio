BYI MOTORS — XAMPP INSTALLATION

1. Install XAMPP and start Apache + MySQL.
2. Copy the folder "BYI_Cars_XAMPP" into:
   C:\xampp\htdocs\
3. Open http://localhost/phpmyadmin
4. Click Import and select:
   database/byi_motors.sql
   OR open the SQL tab and paste its contents.
5. Visit:
   http://localhost/BYI_Cars_XAMPP/

DATABASE:
   Name: byi_motors
   Username: root
   Password: (blank by default in XAMPP)

FEATURES:
- Premium responsive automotive landing page
- Three.js interactive 3D hero vehicle
- JC monogram / club-style branding
- MySQL vehicle catalogue
- Contact/private-viewing form saved to MySQL
- Mobile responsive design
- Google Fonts + Unsplash remote vehicle photography

If your MySQL root account has a password, edit config.php.
The 3D hero and remote vehicle photos require internet access in the browser.
