K.O GAMING — XAMPP INSTALLATION

1. Install/start XAMPP.
2. Start Apache and MySQL.
3. Copy the entire "KO_Gaming_XAMPP" folder into:
   C:\xampp\htdocs\
4. Open phpMyAdmin:
   http://localhost/phpmyadmin/
5. Create/import the database using:
   database/ko_gaming.sql
   (The SQL itself creates the "ko_gaming" database.)
6. Open:
   http://localhost/KO_Gaming_XAMPP/

DATABASE
Database: ko_gaming
Username: root
Password: blank by default in XAMPP

If your MySQL root account has a password, edit config.php.

CUSTOMIZATION
- Main page: index.php
- Design: assets/style.css
- Interactions: assets/app.js
- Database: database/ko_gaming.sql

The site uses Google Fonts from the internet for Orbitron and Rajdhani.
If you need a fully offline version, replace those fonts with local font files.
